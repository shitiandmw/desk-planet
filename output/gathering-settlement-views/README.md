图片均为 1536 × 1024 PNG。基准图直接采用已确定原图，其余视角通过 gpt-image 技能和 gpt-image-2.5-sunburst 生成。总览和设施索引由 Pillow 排版。

本组是生成式概念视图，镜头和局部细节尚未精确配准。后续建模以基准图和固定物件清单为主要依据，再通过同一三维场景统一全部视角。图中遮挡可以改变可见设施的数量，但不代表增加或删除设施。

完整设计规范位于工作区的 docs 目录；全部已确定图片和多视角图片已经整理到 docs/assets，并通过相对路径关联。

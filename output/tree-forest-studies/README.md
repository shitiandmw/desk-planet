# 树木与林地修订

本轮比较三种树冠方向，并将 A 方案放回采集聚落检查整体效果。

[三版造型与场景试放](comparison.jpg) · [场景前后对比](settlement-comparison.jpg)

| 图片 | 重点 |
| --- | --- |
| [A · 疏朗阔叶](A-open-broadleaf.png) | 均衡冠幅、可见分叉，作为通用资源树的优先候选 |
| [B · 挺拔树冠](B-upright-crown.png) | 竖向层次与较窄冠幅，检查林间空隙 |
| [C · 舒展伞冠](C-spreading-crown.png) | 横向分枝与更宽的冠幅，需要较大的间距 |

| [现有采集聚落基准](baseline-settlement.png) | 用于比较植被调整前后的效果 |

修订重点是减少细碎树冠颗粒、露出树干、在林间留出空隙，并让树桩、原木堆和搬运通道帮助表达采集玩法。单体研究图重点检查树形，场景试放用于收敛实际比例。

三种造型均为候选；本轮建议优先细化 A，尚未替换所有文明阶段及多视角的植被。图片为静态设计，未实现树木模型或采伐动画。

原图尺寸为 1536 × 1024 PNG。使用 gpt-image 技能和 `gpt-image-2.5-sunburst`，质量为 `high`；对比图使用 Pillow 排版。`prompts.json` 记录提示词、参数和参考图关系。

# 建造与文明经营游戏 · 策划知识库

建立：2026-10-19。服务项目：微缩星球。用途是支持持续提出、实现和验证设计决策。

这里的“资深策划知识库”指证据、设计方法、反例和验证记录的积累；资料整理不等同于完成原作实机评测，也不能代替玩家试玩。

## 阅读顺序

1. [来源目录](sources.md)：每个机制可回溯到开发者介绍或开发日志。
2. [游戏机制卡片](game-patterns.md)：原作事实、玩家决策、项目借鉴与不适用之处。
3. [设计原则](design-principles.md)：核心循环、空间取舍、反馈、失败恢复与认知负担。
4. [经济与文明进阶](economy-and-progression.md)：资源用途、产能计算、晋级与六时代规划。
5. [试玩与迭代方法](playtest-method.md)：可验收指标、观察办法与证据边界。
6. [开发清单](../development/backlog.md)：优先级、依赖、验收条件和状态。
7. [迭代记录](../development/iterations.md)：本轮改了什么、验证结果、下一轮问题。

## 证据规则

- **来源事实**：仅表述实际读到的官方页面内容，标来源 ID；不把商店宣传当作平衡数值或可玩性结论。
- **设计推断**：明确说明从原作机制推导出的本项目方案，允许被测试推翻。
- **实施状态**：以代码、自动检查和浏览器操作为依据，区分已完成和计划。
- **玩家体验**：自动化操作能验证功能，不能证明“好玩”。保留玩家是否理解、是否愿意继续、是否感到重复等开放问题。
- 新增资料先核对原文，再补机制卡和适用条件。没有证据的精确产率、版本状态或玩家反馈不写入事实层。
- 来源页面全文仅用于临时阅读；知识库保留原创摘要、出处和短引文，不复制游戏资产或整篇第三方文章。

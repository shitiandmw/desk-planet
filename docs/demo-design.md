# 文明初生 0.2 · 设计与实现

更新：2026-10-19。依据：用户授权持续收集资料、建立策划知识库并按开发清单迭代。

## 这一轮解决的问题

原有开局能建造、发展人口和研究，但三个目标之后缺少用途和方向；农业缺少空间取舍，复杂产业没有缺料解释。

本轮按三组能力推进：连续章节与可读收支；农业灌溉与储粮；矿石、金属、工具、零件的加工。知识依据与适用边界见[策划知识库](knowledge/README.md)，未完成系统见[开发清单](development/backlog.md)。

## 保持同一颗星球

完整球体半径 8.4、建筑基础缩放 0.55，球心不变；地块和建筑朝向共享单位法向坐标。水面、四组实体云、云影、径向降雨和自由旋转沿用已批准版本，不恢复透明云缘贴片。

新设施遵循原有木构、石材与自然色调。水井使用石圈、绳索和木盖，粮仓用高脚木构，矿场有矿口和轨道，冶炼炉有炉体与运行时炉火，锻造有工作台，机械工坊有运行齿轮。高大工业设施的选址为树冠预留额外间距。

灌溉线沿球面测地距离绘制，预览和数值均使用半径 2.8。只有选中水井或预览水井时显示。范围变化才更新几何，避免重复分配。

## 经济与进阶

`GameSimulation` 仍是唯一经济状态。新增配方、容量、库存目标、累计生产、章节和正式时代。加工完成才原子扣料；缺料不透支，多工人按同一步的剩余库存依次执行。建设 / 研究保留已有预留退款机制。

四章分别检验安家、农业能力、金属加工和机械投入。第一章允许先研究农业或工具；农耕章允许灌溉或扩田；时代依实际产能成果变化。完成章节不强迫重开星球。

研究结束释放实际人手，保留岗位请求。食物满仓时停产，但足够的潜在食物供给仍能支持迁入。旧存档超额储粮保留，降低新规则造成的进度损失。

## 瓶颈反馈的迭代

实际追加冶炼炉时观察到：矿石耗尽使当前加工消耗变成零，瞬时净值反而显示矿石 +20 / 分，掩盖了需求 30 的结构性缺口。

因此界面改为“满负荷岗位收支”，同时显示供给与需求；设施另列当前可运行产能及停工原因。玩家暂停规划时也能看到 -10 缺口。该修订来自试玩观察，随后加入回归测试。

## 存档与验证边界

v2 存档兼容 v1，保留建筑 / 人口 / 资源及任务。迁移后新增累计产量从新系统开始；本地备份、导出、导入和撤销导入提供恢复路径。

数值脚本验证两条合理路线能走通，浏览器用实际按钮验证四章和存档。自动化不能判断真人是否觉得有趣，后续根据实际试玩调整等待、目标吸引力和操作负担。

当前覆盖采集、农耕和工业起步。电力、真实运输、环境、信息、AI、星际与联网有独立开发项；不把未来表格当作已经实现的功能。
